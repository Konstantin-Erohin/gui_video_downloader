# Бинарники, включаемые в приложение

Для текущей macOS ARM64-сборки здесь используются `ffmpeg` и `ffprobe`, которые
пользователь собрал из официального исходного кода **FFmpeg 9.0.2**.
Источник архива `ffmpeg-9.0.2.tar.xz`:
[официальная страница FFmpeg](https://ffmpeg.org/download.html#build-mac).

После распаковки пользователь выполнил в папке исходников:

```bash
./configure
make -j4
```

Сборка заняла около пяти минут. Затем оба полученных файла были перенесены в эту
папку проекта и включены в приложение через `build.py`. `make install` не использовался.
Это локальная `bin/` проекта, не системная `/bin`. FFmpeg из Homebrew не копировался.

Полные шаги, требования и пояснения команд находятся в [основном README](../README.md).

## Содержимое для разных платформ

- macOS: `ffmpeg`, `ffprobe` с правом исполнения (`chmod +x bin/ffmpeg bin/ffprobe`
  из корня проекта).
- Windows: `ffmpeg.exe`, `ffprobe.exe` для архитектуры целевой Windows-сборки.
  Бинарники macOS для неё не подходят.
- Необязательно: `deno` / `deno.exe` для поддержки JavaScript в yt-dlp.
  Если файл есть, `build.py` включит его автоматически.

Сборщик проверяет наличие и запуск обоих инструментов и упаковывает их внутрь
приложения. Для запуска исходного кода downloader сначала ищет их здесь, затем в PATH.

Перед передачей приложения на другой Mac проверьте его там без установленного FFmpeg.
Сохраните сведения о версии, исходники и лицензии используемой сборки.
