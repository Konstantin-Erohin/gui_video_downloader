# Бинарники приложения

Папка `bin/` содержит внешние исполняемые файлы, используемые Video Downloader.

## Содержимое

### macOS Apple Silicon (ARM64)

```text
bin/
├── README.md
├── ffmpeg
├── ffprobe
└── deno
```

### Windows x64

```text
bin/
├── README.md
├── ffmpeg.exe
├── ffprobe.exe
└── deno.exe
```

## Назначение

- `ffmpeg` / `ffmpeg.exe` — обработка и объединение видео- и аудиопотоков;
- `ffprobe` / `ffprobe.exe` — получение информации о медиафайлах;
- `deno` / `deno.exe` — JavaScript runtime для `yt-dlp`, необходимый для полноценной поддержки YouTube.

Бинарники должны соответствовать целевой операционной системе и архитектуре:

```text
macOS → Apple Silicon (ARM64)
Windows → x64 (Intel/AMD)
```

Бинарники разных операционных систем и архитектур нельзя смешивать.

Бинарники не хранятся в Git-репозитории.

Полные инструкции по подготовке бинарников, запуску из исходного кода и сборке приложения находятся в [основном README](../README.md).

## Лицензии

FFmpeg и Deno являются сторонними компонентами и распространяются на условиях собственных лицензий.

При распространении готовых сборок необходимо учитывать лицензии включённых компонентов.
